# 安卓平板表格增强插件设计

日期：2026-11-04。状态：用户已批准；开发与验证中。

## 目标与范围

基于 niixyz64-star/table-tune 的 2.0.1（提交 0dff02b），制作用户自己的 Obsidian 表格插件。第一版包含安卓平板适配、复制与 HTML 导出、固定表头与首列、一键整理、单元格底色与重点标记。保留原有合并、拆分、行列编辑和历史功能。

按用户后续指示，以原插件 ID `table-tune` 替换原插件，中文名“表格工具 · TableTune”，版本 2.1.0。保留 MIT 许可和原作者声明，直接兼容已有 `data.json`。不安装第二份插件，不批量改写 Markdown，不删除、隐藏或清空已有表格。新增固定、样式选项默认关闭，现有列宽、合并与对齐沿用原数据。替换仅覆盖 main.js、manifest.json、styles.css；data.json 不在安装包内。

## 安卓触控

工具栏主要按钮最小命中区域 44 CSS px，窄容器允许横向滚动，更多操作打开菜单。桌面保留鼠标与键盘操作。

触控普通滑动用于浏览；单击进入文字编辑；通过“选择区域”进入显式选区模式，点选起始与结束单元格，避免要求 Shift 或右键。合并单元格按原有逻辑扩展为完整矩形。工具栏操作保留已有选区，不因为按钮获焦而丢失。

调整尺寸必须从明确手柄开始，扩大命中区域；使用 Pointer Events 和指针捕获，仅在主动拖动手柄时抑制浏览手势。pointercancel、lostpointercapture、卸载均释放状态。支持手指及鼠标，不将所有触控拦截为选区。

移动端工具栏按当前面板、visualViewport 和安全区域定位，软键盘弹出后保持可见；屏幕旋转、分屏与容器尺寸变化重新布局，不只依赖整个窗口宽度。

## 固定表头和首列

每张表独立开关“固定表头”“固定首列”，允许同时开启。表头定义为第一行，首列定义为第一逻辑列；交叉单元格层级高于其他固定单元格，具有不透明主题背景。

宽表在表格内部横向滚动；表头在有高度限制的表格视区内部纵向滚动时固定。启用固定表头时采用最大高度为可用面板高度约 60% 的表格视区，避免整篇笔记滚动与 overflow 横向容器使 sticky 失效。关闭固定表头后恢复自然高度。实际高度随键盘和容器变化调整。

合并区域跨过固定边界时阻止开启对应固定选项并解释原因，要求先拆分跨界合并；开启后新增跨界合并同样阻止。读取已有跨界布局时暂时停用对应固定效果并保留数据，不自动拆分或丢弃内容。

## 一键整理

- 适应屏幕：按当前表格容器可用宽度分配列宽，最低列宽 64px；列数过多则保留横向滚动，避免挤压至不可编辑。
- 按内容调整：测量实际显示内容，单列宽限制在 64–480px。合并单元格的内容需求分摊至覆盖列，不把总宽重复应用到每一列。
- 平均列宽：优先对所选列均分其现有总宽；没有列选区时对整表均分，保留总宽。
- 自动换行：当前表的开关，支持中文、长链接与长英文串，关闭后使用不换行显示和横向滚动。
- 重置布局：仅清除当前表手动列宽、行高及换行设置，重新应用默认尺寸；不删除文字、合并、对齐、底色、标记与固定设置。

所有持久化布局修改应进入原有编辑历史，一次操作对应一次撤销。工具栏提供撤销与重做入口，供无外接键盘使用。阅读视图使用已保存布局，修改操作在实时预览执行。

## 快捷样式

对当前单元格或矩形选区设置底色，提供默认、黄、绿、蓝、粉、紫六项主题适配预设。保存语义颜色键，深浅主题转换后仍清晰。重点标记采用独立的左侧强调条和强调样式，可与底色并存；不等同于修改单元格 Markdown 文字。

清除样式仅清除选区底色和重点标记，不改变尺寸、合并或内容。合并单元格以锚点保存样式；合并时保留左上角样式，拆分后原覆盖区域继承合并单元格样式。插入和删除行列时重映射样式坐标，删除的格子不残留样式。

## 复制与 HTML 导出

复制选区同时尝试提供 text/html 和 text/plain（TSV），使支持 HTML 表格的 Excel 粘贴保留合并、尺寸、对齐和样式；纯文本复制始终提供明确按钮。没有区域选区时可通过整表菜单复制全表。

TSV 中多行、制表符和引号字段按兼容表格粘贴的方式转义；合并区域由锚点输出文字，被覆盖位置输出空字段。保留文本原值，不在插件内执行表格公式。

HTML 导出生成独立 UTF-8 .html 文件，包含 table、rowspan、colspan、列宽和必要的内联样式，不携带工具栏、拖动手柄、内部标识和隐藏占位单元格。清理脚本、事件属性与危险链接，不直接导出未经处理的编辑器 innerHTML。

安卓 WebView 不支持富文本剪贴板时明确提示并允许纯文本复制或 HTML 导出，不报告虚假的富文本复制成功。导出通过 Obsidian Vault API 保存到“表格导出”文件夹，使用安全文件名与不覆盖旧文件的后缀；完成后提示文件路径。该方式在桌面和安卓共用，不依赖 Electron、Node 文件系统或浏览器下载行为。

## 数据与实现边界

新增固定选项、换行选项和单元格样式，以笔记路径和表格 ID 为键保存，扩展现有数据结构并保留未知字段。同 ID 替换直接复用原插件数据，不需要导入或迁移命令；缺少原数据时正常从空配置启动。本版不承诺插件配置会被现有同步工具自动同步。

沿用现有表格 ID 与编辑历史，增加字段时一并扩展快照、恢复及行列重映射。新增功能按职责拆成触控控制、布局、样式、导出模块，打包为可直接安装的 main.js；不无关重写上游编辑器。

## 验证与交付

自动验证：逻辑网格和合并导出、特殊字符与危险 HTML、TSV 多行值、列宽下限、选区样式重映射、数据兼容与撤销恢复。交互验证：触控滑动不误选、手柄拖动取消、工具栏选区保持、固定交叉层级、横竖屏与软键盘可用区域变化、同一笔记多表互不影响、阅读与实时预览一致。

使用隔离示例表格和浏览器移动端模拟验证；安卓真机、系统剪贴板和真实 Excel 粘贴必须明确列为待真机验收，不将模拟结果称为真机通过。交付安装包 main.js、manifest.json、styles.css、保留的 LICENSE，以及安装与安卓验收说明。

## 本次设计审阅

范围对应用户选定的四类功能和安卓适配；未加入模板、排序筛选、AI、全屏编辑或其他扩展。开发前需用户审阅本文件，之后进入实现计划和开发。
