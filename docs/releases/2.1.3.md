# 表格工具 · TableTune 2.1.3 图标空白兼容修复

针对安卓平板“悬浮栏位置正确，但所有图标空白”的反馈：

- 工具栏和表格入口改用随插件打包的 SVG 图标，不依赖 Obsidian 图标库、字体或网络。
- 为图标明确设置尺寸、描边和颜色继承，并保护图标免受普通移动端 SVG 重置样式影响。
- 保留 2.1.2 的原位悬浮位置、边缘触发、合并拆分与居中、行列选择和图标自定义。

在 BRAT 中将 `w3330442790-sys/obsidian-table-tune` 更新到 2.1.3，重新启用插件或重启 Obsidian。手动安装只覆盖 main.js、manifest.json、styles.css，保留 data.json。

验证：19 项逻辑测试、34 项隔离浏览器检查通过。测试现在模拟宿主图标接口没有输出，另行模拟隐藏 SVG 和清空描边的移动端样式，并检查明暗主题的实际图标几何和截图。尚未直接观测用户安卓端具体的失效环节，仍需真机确认。
