# 表格工具 · TableTune 2.1.0

安卓平板个人增强版，基于 niixyz64-star/table-tune 2.0.1，保留 MIT 许可和上游归属。

- 安卓触控：44px 工具栏、两点选区、软键盘/分屏避让、安全调整列宽行高。
- 固定表头、固定首列；两项独立开关，按表记忆。
- 一键整理：适应屏幕、按内容调整、平均列宽、换行、重置布局。
- 快捷样式：五种主题适配底色和重点标记，支持撤销重做。
- 复制到 Excel、纯文本 TSV 复制、保留合并与样式的 HTML 导出。

## BRAT

仓库：`w3330442790-sys/obsidian-table-tune`。在 BRAT 设置中选择 Add beta plugin，填写上述地址并选择最新版本。Release 已提供独立 main.js、manifest.json、styles.css 附件。

## 已有表格

插件 ID 继续使用 `table-tune`，直接复用原 data.json，不批量改写笔记，新增固定与样式默认关闭。已有原版时，只从 BRAT 跟踪列表移除旧仓库更新来源，再添加本仓库；不要在 Obsidian 中卸载插件，不要删除原 table-tune 目录或 data.json。

最低 Obsidian 1.14.4。更新后重新启用插件或重启 Obsidian。
